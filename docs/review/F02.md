# F02 — reject ambiguous envelopes

The exploit regression signs the sealed payload, appends an unrelated open
payload and submits the unchanged signature. It failed on the baseline because
the server returned OK and stored both fields. With the validator, the RPC is
rejected and no locker is stored. `:server:test --tests '*ReviewRegressionTest*'`
passed with the isolated Fullhouse dependency manifest.

`LockerEnvelope` is shared by consumers and server writes. It requires exactly
one supported representation and rejects unsupported encrypted combinations.
Client ingress, extension outputs and authenticated metadata are tracked as
integration dependencies of F02, F03 and F38.
