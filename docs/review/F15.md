# F15 — consistent versioned deletion reads

The baseline returned no identified locker from GetLocker after a delete and
decoded empty tombstone bytes as a live locker in GetLockers. GetAllLockers hid
the tombstone. The new regression failed against that behavior.

All three reads now return the same identified tombstone with the committed
version and null body. Absence remains distinguishable from deletion. Four
`ReviewRegressionTest` cases pass with the patched isolated ktstore manifest.
