# F06 — session possession at the public unary boundary

The baseline public room module accepted unsigned subscriptions. The regression
temporarily restored that route composition and failed its missing-proof
assertion. The authenticated module passes missing proof, substituted room,
valid proof and repeated nonce checks. Proofs sign a V2 domain, operation,
session ID, normalized request digest, timestamp and nonce with the stored
session authority key. They expire after 60 seconds with 5 seconds of clock skew.

Public room, push and session modules install authenticated server wrappers;
trusted in-process implementation seams remain available. Replay identities and
the mutation commit atomically. A bounded indexed prune removes expired proof
identities. The additive server schema uses a configured version 3 → 4 migration.

`:server:test --tests '*SessionProofBoundaryTest*'` passed with the isolated
workspace manifest. Connector signing and session revocation cleanup remain
integration dependencies; this finding is not complete until they pass together.
