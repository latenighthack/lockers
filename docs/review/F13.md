# F13 — monotonic committed versions

Baseline reproduction submits the same parent-zero initial write twice. Both
committed, first at version zero and second at version one. The regression now
requires a first commit at one and a second conflict at one. The security
regression class passes all three tests with the isolated dependency manifest.

Absence has parent zero; only a zero parent can create content or a tombstone.
All commits advance to a strictly positive next version. Negative parents and
`Long.MAX_VALUE` cannot advance. Existing version-zero rows remain readable and
advance to one through the normal comparison guard.
