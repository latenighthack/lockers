# F10 — one atomic source-write path

The baseline fault injection throws while saving content after a valid ratchet.
It failed the regression because the new authority key survived without content.
The regression now proves the old key and absent content survive the failure.

Single writes use the existing receipt/outbox batch transaction, including legacy
wire calls. Content, authority updates and delivery intent share one delegate and
commit. Removed the separate legacy source/agent execution path. The effective
outbox can be composed from the same built-in LockStore database for direct
embedders. Delete and standalone authority operations share the room transaction.
The worker drains durable intents; no network delivery runs inside the source
transaction. Room source commits use the room transaction key.

Seven targeted security/version/alias/ratchet regressions pass. F08 adds the
commit-time owner proof and multi-connection PostgreSQL verification.
