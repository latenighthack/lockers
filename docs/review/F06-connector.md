# F06 — authenticate public session unary operations

The root server change reproduces and rejects unauthenticated session mutation. The client counterpart signs subscription/snapshot, push register/revoke and destroy requests with the current connected session key. V2 proofs bind operation, session ID, SHA-256 of the proof-free encoded request, timestamp and a fresh 32-byte nonce. Session changes during signing abort obsolete work. Each retry regenerates its proof while preserving push credential revision. Destroy clears the local session challenge and closes the facade after acknowledged server revocation.

Public push requests use positive monotonic revisions. The test passes (`/tmp/connector-F06-client.log`); root/build worker validate production wrappers and persisted nonce consumption separately.
